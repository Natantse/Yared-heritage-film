# Yared: The Voice of Ethiopian Heritage

An AI-powered short film celebrating Saint Yared and Ethiopia's traditional sacred musical heritage.

## Project overview

This project explores how AI can help preserve and share Ethiopian cultural heritage with international audiences.

## Film details

- **Subject:** Saint Yared and Ethiopian musical heritage
- **Narration:** Amharic, AI-generated
- **Subtitles:** English
- **Visual style:** Traditional Ethiopian painting
- **Target audience:** International audiences
- **Duration:** 60–90 seconds

## Pipeline

The project will include five stages:

1. Keyframe generation
2. Video generation
3. Original music generation
4. Amharic narration generation
5. Film assembly and export

## Status

Project setup and creative planning in progress.

## AI disclosure

The film uses AI-generated visuals, narration, and music. Historical representations are artistic interpretations, not verified portraits.
