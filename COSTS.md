## Cost Measurement

For each generation, the project will record:
- Tool or model used
- Number of generations
- Processing time
- Actual cost, if any
- Free credits or free-tier usage

## Budget Approach

The project will prioritize accessible tools and free tiers where possible.

No estimated prices will be presented as actual spending. Final costs will be updated after the tools are tested.
